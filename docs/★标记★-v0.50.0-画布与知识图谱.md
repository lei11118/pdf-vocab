# v0.50.0 / build 93：画布、工具及生词图谱

本次在当前代码上向前修改，未回退文件、降级依赖或调用 Claude Code。

## 变更与使用

1. `Sources/Reader/Ink/InkContinuity.swift`、`MetalInkHost.swift`、`InkStrokeModel.swift`：统一逻辑笔迹、共享 ID、精确页边界插值。页面仍保存局部矢量控制点，显示时重组连续笔迹；整笔擦除、套索选中与撤销关联所有片段。渲染保持视口窗口及像素预算，避免整本文档的大纹理。旧笔迹缺少 ID 时保持独立，不推测合并。
2. `Sources/Reader/Pencil/SmartRulerView.swift`：解析式无限尺线，只画当前可见刻度。手指平移、双指以触点中心旋转、常用角度吸附；松手停住，PDF 滚动不改变尺子屏幕位置。关闭再打开重置到中心。
3. `Sources/Reader/Ink/InkLaserOverlay.swift`：激光笔瞬时红色发光轨迹，上限 192 点，抬笔后淡出，不进入笔迹数据库、撤销或导出。
4. `Resources/ink-material-atlas-v2.png`、`InkMetalCanvasView.swift`：AI 生成的独立石墨／蜡笔颗粒区，分别用于铅笔和蜡笔。钢笔继续使用压力、速度和收笔变化；荧光笔维持固定宽度及 0.3 透明度，同笔自交不反复加深。真实控笔手感需 Apple Pencil 真机判断，不能仅靠素材保证。
5. `Sources/Reader/ReaderView.swift`、`Sources/Library/LibraryView.swift`：生词本全屏打开，继续使用原有 DS 风格。
6. `Sources/Vocab/VocabListView.swift`：卡片仍在网格中，手动排序模式下长按拖动，悬停预览顺序、边缘自动滚动、落下保存；退出拖动范围或离开界面取消预览。最近／字母排序及搜索期间不保存拖动排序。分组筛选只调整可见词所占的排序槽位。
7. `Sources/Vocab/VocabGraph.swift`、`Sources/Storage/AppDatabase.swift`：离线图谱支持词根词缀、同近义、混合三种模式；搜索、缩放、平移、节点拖动并按模式保存位置；点击连线查看来源依据。上限 250 节点、1,500 条关系，以控制布局成本。关系查询和布局在后台执行。
8. `Sources/Reader/Ink/InkPDFRendering.swift`、`AnnotatedPDFExporter.swift`：批注 PDF 导出支持当前 JSON 笔迹，保留旧 PencilKit 数据兼容。现有批注导出器最终仍合成为图片页面，不保留 PDF 文字层，颗粒材质不会逐像素复刻到导出结果。

## 数据覆盖与许可

`Resources/LexicalSources/lexical.sqlite` 实查：185,081 条词形—义项关联，127,311 个不同词形；107,519 个英文义项；24,158 条词素词例关联，14,221 个不同词。它们是资源总体覆盖，不能解释为用户生词本覆盖率，界面中的关联仍取决于具体词条。

- Open English WordNet 2025：共享英文义项与词性才连同近义线，一词某义项相同不表示所有含义相同。CC BY 4.0 和 Princeton WordNet License。
- Colin Goldberg / morphemes：MIT；只接受来源明确列出的例词，并检查词素位置，不把词形还原或任意子串当作词根。
- 已研究中文近义资源；尚未核准所查候选数据的完整再分发许可，因此本版未打包中文近义词库，也未仅凭译文重叠建立确定关系。此项仍可扩充。
- 来源、完整许可及 SHA-256 随资源保留，归属见根目录 `THIRD_PARTY_NOTICES.md`，重建脚本为 `scripts/build_lexical.py`。
