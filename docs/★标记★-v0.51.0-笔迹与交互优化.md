# v0.51.0 / build 94：笔迹、图谱、缩放和取词

## 改动与原因

| 路径 | 改动 | 原因与验证范围 |
|---|---|---|
| `Sources/Reader/Ink/InkMetalCanvasView.swift` | 为笔迹轮廓增加外侧抗锯齿覆盖，内外对称渐变；圆头按像素尺寸使用 24～128 段；合成采样改为线性 | 原先覆盖渐变全在轮廓内侧，且圆头固定 10 段。新增 Metal 像素读回测试检查轮廓外的部分覆盖、实心中心和远处透明。矢量中心线存储格式不变 |
| `Sources/Reader/Ink/MetalInkHost.swift` | 捏合期间复用渲染表面，结束后恢复当前密度；更新坐标时禁用隐式图层动画；关闭缩放越界弹跳 | 减少缩放过程中反复分配纹理及图层补间。PDFKit 仍负责连续缩放；不能以源码修改代替真实设备上的帧率与稳定性测量 |
| `Sources/Reader/PDFKitView.swift`、`Sources/Reader/Selection/ReaderCoordinator.swift` | 捏合或回弹期间不写缩放上下限；正常滚动／缩放期间不执行选区异常跳页拉回 | 避免正在缩放时应用层再次干预 PDFKit 的缩放或页码。保留既有 100%～4000% 限制 |
| `Sources/Reader/Pencil/SmartRulerView.swift`、`ReaderCoordinator.swift` | 保存尺子在 PDF 文档视图中的锚点及方向，滚动／缩放后投影回屏幕；尺子大小随文档缩放；角度显示为 `45°` | 此次要求覆盖旧版“固定屏幕位置”的行为。尺子仍可手指移动、双指旋转、角度吸附；关闭再打开仍回到当前屏幕中心 |
| `Sources/Library/LibraryView.swift` | 首页页头增加独立知识图谱按钮，无需先打开生词本 | 保留生词本内的便捷入口及原有 DS 风格 |
| `Sources/Vocab/VocabGraph.swift` | 增加浅网格、星群标题、轻描边与阴影；网格、节点、文字和连线随视图缩放；统一节点拖动坐标空间 | 沿用 DS 配色、字体及间距；不引入外部 UI 依赖。美术观感和多指交互仍需实际安装验收 |
| `Sources/Vocab/VocabGraphPhysics.swift` | 节点排斥、连线弹簧、拖动节点固定、松手惯性和阻尼；每次唤醒有计算次数上限 | 物理计算使用图谱坐标，缩放不改变质量；同一对词的多个词义依据只形成一根弹簧；支持减少动态效果，非前台停止计算 |
| `Sources/Vocab/VocabGraph.swift` | 节点位置批量事务保存，并记录布局所属模式 | 避免逐个提交大量数据库事务，也避免切换模式时将旧位置保存进新模式 |
| `Sources/Reader/Selection/SelectionKit.swift`、`ReaderCoordinator.swift` | 初选只接受一个完整单词，删除初选整行兜底；取词模式 Pencil 落笔即选；手指轻点也可选词；达到拖动阈值前保持初选整词 | 修正“刚识别整词就被细微移动改成部分字母”的路径。之后保留字符级拖动及手柄调整；扫描 PDF 使用已有 OCR 单词框，未完成 OCR 时不能即时凭空识别 |
