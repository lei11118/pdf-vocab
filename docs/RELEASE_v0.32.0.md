# 跃文 v0.32.0(build 70)

> 手写层在最新版基础上**重建**,不是回退。基座 = v0.30.0(工具状态单一真相源、四边出血、无书法笔),换掉了它处理“工具套用”和“跨页”的两块实现。

## 你报的三个问题,逐条对应

### ① 除了橡皮和尺子,所有工具都只有黑笔效果

**根因**:工具套用被写成「延迟到下一个 runloop 再执行」,并且在**排队之前**就记下“已套用版本号”。只要那一刻绘制层还没建好,任务会直接返回,而版本号已经是新的 —— 之后再没有任何人重新套用。画布便永远停在初始化时的保底黑笔 `PKInkingTool(.pen, .black, 2.5)`。橡皮和直尺之所以正常,是因为它们走的是同步的 `setEraserMode` / `setRulerActive`。

**改法**:
- 工具套用**全部同步执行**(模式标志 → 笔具 → 直尺),provider 未就绪时**不记版本号**,留给下一次调用;
- 加一道兜底:每次进入书写,画布都向 provider **再取一次当前笔具**;
- 诊断日志升级为 `pencil: apply ink=pen:#0A0A0A:9.6 …`,直接打印真正赋给画布的**墨型 / 颜色 / 宽度**——真机上一眼能分清“没套上”和“套上了没渲染”。

### ② 直尺出现多个

PencilKit 的直尺是**每块画布各带一把**。以前 `applyModeState` 对所有页都设 `isRulerActive = true`,同时可见几页就有几把。

**改法**:直尺只挂在**视口中心那一页**,`applyModeState` 不再碰直尺;滚动、缩放、旋转时 `refreshRulerFocus()` 自动把它挪到新的焦点页。

### ③ 从第 2 页往上写连接第 1 页仍然截断

v0.30 的做法是“只渲染、不搬迁”——在 PDFView 上叠一层镜像画布去画页面外的墨。真机上那层会被 PDFKit 翻页重建的页视图压到下层,页缝处正好被裁掉。

**改法**:跨页回到**抬笔后按页边切开、把越界段搬到邻页**这条路上,并重写为**幂等结算**:
- 每页内容变化后 0.1s 结算一次:凡是有采样点越过页面矩形的笔迹,按页边**插值出边界点**切成两半,页内段留下、页外段平移给邻页;
- 向上搬运的位移用**上一页的页高**(封面/插页尺寸不同也不会错位);邻页叠层还没建时,直接写进那一页的墨迹库,翻到就能看见;
- 幂等:搬完这一页就没有越界段了,重复调用不改任何东西;撤销/重做后的 0.8s 内不结算,避免“撤销一笔跨页墨迹又被立刻切开”。

## 与上一版的差别

| | v0.30(你装的上一版) | v0.32(本版) |
|---|---|---|
| 工具套用 | 异步排队,可能被吞 | **同步 + 未就绪不记版本 + 进入书写再兜一次** |
| 直尺 | 每页各一把 | **只在焦点页一把,跟随滚动** |
| 跨页 | 只渲染不搬迁(被页视图裁) | **抬笔切分搬页(幂等结算)** |
| 书法笔 | 已移除 | 已移除(不回退) |
| 工具状态 | 单一真相源 `PencilToolState` | 保留 |

## 安装

下载 `PdfVocab-unsigned.ipa`,AltStore / SideStore / Sideloadly 自签安装。Bundle ID `com.lei11118.pdfvocab` 未变,覆盖安装不丢数据。

## 请重点确认

1. 切到钢笔 / 铅笔 / 荧光笔 / 蜡笔 / 套索,**墨色与笔宽是否跟着变**;
2. 开直尺后是否**只有中间一把**,滚动到下一页尺子是否跟过去;
3. 在第 2 页顶部往上写越到第 1 页,页缝处是否连续。

若仍有问题,请把诊断日志里 `pencil: apply ink=` 与 `pencil: overflow` 开头的行发我 —— 前者回答“工具套上没有”,后者回答“跨页搬没搬”。
