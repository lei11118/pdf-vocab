# v0.69 工作区与多窗口实现说明

本文记录 `40bd7f9` 的源码行为。完整 CI 通过 90 项单元测试及 4 项界面测试；竖屏截图与横屏测试录屏已检查。真实 iPad / Pencil 验收尚未确认，不能将模拟器结果视作硬件手感验证。

## 工作区布局

入口为 `Sources/Library/LibraryView.swift`。全局颜色、材质、书架网格及真实文档数据沿用现有实现，本轮替换工作区的导航与内容组织。

| 可用容器宽度 | 导航与主区 |
| --- | --- |
| ≥900pt | 224pt 固定侧栏与独立滚动的文档主区；侧栏自身可滚动 |
| 760–899pt | 隐去侧栏；继续阅读与 280pt 词汇/图谱动作区并排；文件夹为横向滚动条 |
| <760pt | 继续阅读、词汇/图谱动作区及书架依次纵向排列；保留横向文件夹条 |

侧栏提供全部文档、未归档、生词本、知识图谱和文件夹。选中文件夹后，主区标题使用真实文件夹名；搜索时主区显示搜索结果并隐藏继续阅读。导入 PDF、新建文件夹、文件夹重命名/图标修改、文档移动和删除、设置及诊断入口仍连接原有动作。

顶部安全区内显示跃文名称、副标题、日期及更多设置。品牌采用局部 28pt semibold rounded 系统字，其他文字继续使用现有语义字体。主区仍使用自适应封面网格；此版没有新增虚构封面、统计或示例文档来填充布局。

## 当前 PDF 在新窗口打开

`ReaderView` 的“更多”菜单在系统支持多窗口时提供“在新窗口打开当前 PDF”。`PdfVocabApp` 使用有类型的 `WindowGroup`，每次请求生成独立 UUID，使同一 PDF 可以有多个阅读场景。

新窗口从请求页码的页首以适宽方式打开；页码限制在文档范围内。它使用正常 `ReaderView`，不再借用生词出处预览的 `jumpTarget`，因此没有该预览路径的永久禁止保存进度行为。新窗口的退出动作关闭对应系统场景。各窗口仍保存同一本书的阅读状态，数据库中最后一次成功保存的状态作为下次打开的恢复位置。

同一数据库、同一文档的窗口通过 `KnowledgeGraphStore.session` 共享实时图谱实例和保存队列。不同文档的图谱实例保持分离。此设计避免同书图谱的多个独立整份快照互相覆盖，但不等同于提供跨设备协同编辑。

## 笔迹保存与撤销

阅读入口统一安装文档级笔迹层，不再根据历史 `documentInkSurface=false` 设置启用逐页整页覆盖路径；安装时清空旧 `pageOverlayViewProvider`，确保单个阅读场景只有一个笔迹写入层。

`DocumentInkEngineSession` 在同一文档仍有窗口打开时保留同一引擎选择，避免并行窗口混用存储格式。文档已经含 Metal 格式笔迹时继续使用 Metal 引擎；其他情况下以首个活跃会话的引擎偏好为准。

Metal 与原生 PencilKit 文档层均按“编辑前 → 编辑后”的差量在数据库事务中合并到最新页面，而不是用窗口的旧缓存替换整页。恢复或变换的笔迹以存活后继笔迹为插入锚点，保留局部叠放顺序；撤销/重做同样通过本窗口的差量执行。页面更新通知驱动其他窗口刷新，正在输入或变换时推迟刷新。

保存失败时保留本地笔迹与待保存基线，不用数据库旧值替换可见内容。失败通知显示“笔迹暂未保存”，可在当前窗口重试。未保存页受到缓存裁剪与其他窗口刷新保护；这不是退出窗口后仍能恢复未写入数据的保证。清空本页也通过当前引擎执行，并进入相应撤销记录。

## 尺子与悬浮释义

`SmartRulerView` 保留文档坐标中的锚点与轴向、随页面滚动和缩放、拖动及旋转逻辑。新增沿边投影线段的实时长度读数，单位为页面 pt，并在结束后延时隐藏；角度圆标与读数保持正向显示。此变化不承诺物理毫米测量，也不改变尺子位置功能。

悬浮释义保留中文释义中已有的词性前缀，例如 `n.`、`vi.`；它移除词典分区标题并保留全部中文释义，不加入英文长释义。词性来自实际词典内容，不推测缺失词性。
