# 0.68 整体界面方向与验收范围

用户授权自行重新设计全部排版和 UI；同时要求图谱网格、连续缩放、取消单击选词、编辑栏显示时可移动胶囊和弧形盘、悬浮译文按内容自适应。保留 PDF、批注、生词及图谱数据和所有业务入口。

## Direction contract

模式为 iPad 原生 Operate / Read。视觉方向是“研究图册”：暖白纸面、深墨绿工作重点、铜色辅助信号，正文和控件保持系统语义字体，英文词条及首页展示标题使用系统衬线。用户要求自行设计，本轮采用代码驱动设计，不以未确认的 AI 概念图作为验收基准。

候选来源按产品关联排列：学术出版物、大学图书馆、植物标本图版、博物馆藏品索引、语言学习笔记、田野研究图册、书籍装帧。方向种子分配第六项；采用田野研究图册的内容层次和留白，保持原生导航与控件。脚本里的字体标本挑战保留“标题与正文层级清楚”的纪律；登机牌挑战保留“状态变化就地可读”的纪律；短视频挑战不适合长文档；地铁图挑战的多色路线会混淆现有高亮；年鉴挑战的印章装饰和手册挑战的硬切动画均不适合阅读，不引入这些装饰或导航。

首屏：继续阅读为深绿主区，词汇和图谱为右侧可操作列表；窄屏顺序堆叠。书架保持封面与真实书名，搜索、文件夹过滤在其上方。词汇页使用衬线词条、清楚的操作/释义/出处分层。阅读页保留纸张本体、顶部文档信息、侧边功能和笔具入口。图谱以低对比网格表现空间坐标，节点与网格共享平移、缩放原点。

材质：内容面偏暖白，工具面轻浮起，不再让每个图标都有双向拟态阴影。主操作用深绿实底，输入和选中态用轮廓/浅绿表达。深色为墨绿灰，阅读纸面维持已有固定纸色，避免修改笔迹颜色。

交互：选词编辑栏只命中自身矩形，禁止用系统菜单的全屏遮罩拦截窗口。缩放使用持续存在的 UIKit pan，不更换手柄或在拖动时移动左上角；紧凑内容与完整内容保持同一视图身份。弧形盘只命中圆弧区域，真实触摸超过拖动阈值时移动盘，悬浮仍负责延展。

悬浮释义：所有中文释义都保留，宽高由系统字体排版测量；短内容不留大块空白；长内容以可用屏幕高度为上限滚动，始终锚定单词上沿。

## Verification matrix

- 明/暗色、834pt iPad、480pt 分屏、300/320pt 窄窗及大字体的实际 SwiftUI 截图。
- 页面：主页、书架/文件夹、词库、词卡/胶囊/句子、搜索、设置、导出、主图谱/书本图谱、笔具盘、弧形盘及悬浮短/长译文。
- 单元/集成：单击不创建选区，双击/长按和链接行为保留；网格的负坐标和缩放密度；悬浮内容高度上限；编辑栏没有模态交互且外部命中不被覆盖。
- 真正 XCUITest 拖动：胶囊跨 140pt 阈值增大再缩回；编辑栏持续显示时移动胶囊与弧形盘；现有阅读/标记模式所有按钮回归。
- 原生平台不运行 HTML/CSS detector。截图不能证明真实 Pencil 硬件事件和跟手帧率，最终报告保留该限制。
