# v0.71.0-beta 测试说明

版本配置：`0.71.0`（build `121`）<br>
用途：内部测试候选。当前工作树尚无对应的 `test-ink`、`build-ipa` 或 IPA 验证记录；本说明是待执行的验收清单，不代表 CI 或真机已通过。

## 本次增量

- **Reader 安全区模糊层**：顶部和底部安全区不再只铺系统材质，而是从 PDF 阅读画面采集缩小图像，经 Core Image Gaussian Blur 处理后以渐变遮罩混入阅读画面。UIKit 画面采集在主线程执行，Core Image 模糊在后台队列执行。需要检查页面变化时图像更新、边缘无黑边、滚动和缩放期间性能稳定。
- **原生 PDF 句子上下文**：根据 PDFKit 选区的原文 UTF-16 ranges 定位唯一句子，保留原文坐标；只有选区与显示 surface 的非空白字符完全一致才生成 context。句子上限为 2048 UTF-16 单元。原文换行会逐个规范化为空格；跨行 context 只有行几何确认相邻且同栏才附加。
- **OCR 句子上下文**：仅在单条 OCR 行有完整、可映射的原文时构建 context。未完成句保留为 fragment，UI 不把它当作可翻译完整句。OCR 跨行 context 暂不提供。
- **单词卡系统对齐候选**：单 Token 选区可进入语境卡；多词选区继续使用现有整句卡。iPadOS 26.4+ 路径将带 Token 标记的 attributed sentence 交给 `TranslationSession`，再从系统返回的 attributed text 提取选中 Token 的译义候选。候选 UI 标注“系统对齐，待校对”，不能当作已验证词典释义。
- **实验开关与回退**：设置页“语境 Token 阅读”默认关闭。关闭时不请求该候选路径。无法确认 context、系统版本或语言支持时，语境卡仍可打开现有词典释义。数学识别暂未开放。
- **语言准备**：上下文候选请求英语 `en` → 简体中文 `zh-Hans`。系统状态为 `supported` 时提示用户准备离线翻译；必须由用户显式操作，不能将“可下载”或准备调用成功当作“已安装”。

## 测试步骤

1. **版本与 CI**：生成 Xcode 工程后，运行完整 `test-ink` 和 `build-ipa`。记录触发 SHA、测试数量、失败数、IPA 版本/build 与校验结果；本说明不预填本次 CI 结果。
2. **默认关闭与原有卡片**：在未开启实验开关的测试配置中打开 Reader，确认普通单词卡、整句卡和既有词典查询正常，且没有语境 Token 候选请求。新安装默认值应为关闭；已有安装需检查设置的持久值。
3. **原生 PDF 选区**：在单栏 PDF 选中完整句中的单词，核对句子上下文定位到当前 occurrence，尤其测试同一句或页面中重复出现的相同单词。再试显示 surface 与原文非空白字符不匹配、空行、明显双栏跳转和不完整片段；这些情况不得出现误句候选。试跨单个正常换行的句子，并确认几何不明确时退回词典。
4. **OCR 选区**：用完整单行 OCR 句和无终止标点片段分别选词；前者可进入候选准备，后者保持 fragment 并可打开词典。跨 OCR 行的选择不得被误标为完整句子。
5. **系统版本与候选**：在 iPadOS 26.4+ 上开启设置开关，测试完整句单词选区、请求取消/选区快速变化，以及系统不支持时的词典入口。检查界面只显示选中 Token/短语候选，不把整句译文当词义。逐条人工校对候选与 source/target attributed ranges；26.4+ API 可用性和“系统 Token 语境候选”设置文案仍待产品/系统行为校对。
6. **语言包准备**：覆盖 `.installed`、`.supported`、`.unsupported`。在 `.supported` 状态下仅通过“准备离线翻译”操作启动准备；检查取消、失败重试、状态刷新，以及安装后重新尝试。确认状态不因 `prepareTranslation()` 返回而被直接标为 installed。真实设备安装与离线行为需在 iPad 上核对。
7. **词典回退**：分别在开关关闭、低于 iOS 26.4、句子不完整、context 不可信、语言不支持和 Token 未对齐时，点“查看词典释义”，确认能打开原有词典卡并返回语境卡。
8. **Gaussian 边缘层**：横竖屏、分屏、滚动、缩放、翻页、切换文档、前后台切换各检查顶部/底部边缘。确认模糊跟随当前 PDF，不留下旧页面图像，不遮住选区或操作，不出现黑边；观察持续滚动时的流畅度、发热和内存。
