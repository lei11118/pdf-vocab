# 跃文 v0.36.0(build 74)

> 修你截图里那个:黑笔由下往上滑,笔迹出现**重影 + 错位碎片**。

## 日志说的很清楚

```
13:30:04.098 pencil: overflow y- page 1 -> 0 pts=42
13:30:04.210 pencil: overflow y+ page 0 -> 1 pts=42    ← 同一块墨被搬回来
…此后每 0.1s 重复一次,page 0 的笔数 1→2→3→4 一路涨
```

横向那段更夸张:`x+ 12→13` / `x- 13→12` 循环几十次,page 12 从 6 笔涨到 **49 笔** —— 这就是图上那两笔旁边的“影子”。

## 三个根因

1. **按「一页高/一页宽」平移,而不是按两页真实的页矩形对齐。**
   实测 page 0 的画布高是 6070,其余页 6069 —— 页尺寸差 0.33pt,乘 3 倍超采样后落点偏出目标页边约 1pt。目标页于是判定“还越界”,又搬回去。

2. **来回搬都判越界 → 无限弹跳。** 每弹一次,源页留下一份裁过的残段,目标页又多一份全段 → 笔数一路上涨,画面上就是重影。

3. **没有去重。** 同一家族(同 `creationDate`)的段被反复追加,没有任何拦截。

## 四条改动

| # | 改动 | 说明 |
|---|---|---|
| 1 | **按真实页矩形对齐** | 新增 `canvasPageRect(page:)`,位移量 = 目标页矩形边 − 源页矩形边,不再依赖“一页高”。两页尺寸不同(封面/插页/0.33pt 差)也严丝合缝。 |
| 2 | **越界判定容差 0.5 → 1.5 画布点** | 吸收亚像素误差,避免“刚好压在边上”被来回判成越界。 |
| 3 | **防弹回** | 同一块墨 1 秒内要从对面页搬回来 → 直接保留页内段、丢掉越界段,并写日志 `overflow bounce blocked`。宁可少一段,绝不再来回搬。 |
| 4 | **搬页去重 + 历史清污** | 送达前检查目标页是否已有“同 `creationDate` 且位置几乎重合”的段,有就视为已送达;页面加载时也做一次去重(日志 `page N dedupe 49 -> 12 strokes`),**把你已经画坏的那页自动修干净**。 |

## 安装与验收

`PdfVocab-unsigned.ipa`,AltStore / SideStore / Sideloadly 自签安装。Bundle ID 未变,覆盖安装不丢数据。

1. 打开你画坏的那页:重影应当已经在加载时被去掉(诊断日志里能看到 `dedupe …`);
2. 用黑笔**由下往上**快速滑一笔跨过页缝:不再出现影子/错位碎片;
3. 竖排、横排各试一次;
4. 跨 3 页的长笔仍应连续,撤销一次整笔消失。

若还有重影,把 `diagnostics.log` 里 `overflow` 与 `handoff dedupe` 两类行发我 —— 前者看是否还在弹,后者看去重有没有命中。
