### 统一撤销组：一条动作 = 一次撤销

以前跨页写一笔会在页缝处被切成两半（这是 PencilKit 每页一画布的必然处理），**撤销却只回退其中一半**；橡皮、形状、书法、清空本页、直线吸附各自用一套撤销，和 PencilKit 自带的撤销栈混着用，顺序不可预期，偶尔还会"撤销按了没反应"。

这一版把整份文档的墨迹撤销收进一条链：

- 新增 `InkUndoStack`：一条记录 = 一组「页 → 该页画面」的前后快照，天然可以**横跨多页**；
- 跨页一笔、橡皮一次拖动、形状一次拖动、书法一笔、清空本页、直线吸附，都只产生**一条**记录 —— 撤销一次整体回退，重做一次整体回来；
- 快照用 `PKDrawing`（写时复制的值类型），落笔时只做引用拷贝，**不增加落笔延迟**；不会出现"每写一笔都序列化整页"的卡顿；
- 撤销/重做装回快照后 0.8 秒内不做跨页切分与吸附，否则刚还原的跨页笔会被立刻重新切开，看起来像撤销无效（这是实现这类"撤销组"最容易踩的坑）。

### 真机验收要点

1. 在页缝处写一笔跨页横线（上下各一半）→ 点**一次**撤销：两页上的那两半应**同时**消失；点一次重做：两半一起回来。
2. 连续写三笔（其中一笔跨页）→ 连续撤销三次：应当按相反顺序逐笔消失，不会剩半截。
3. 橡皮擦一刀、画一个箭头、写一笔书法 → 各自撤销一次即整体回退。
4. 撤销后停一秒，画面不应"自己又变回去"。
5. 诊断日志关键字：`pencil: undo push <动作> pages=[…] depth=…`、`pencil: undo <动作> pages=[…]`、`pencil: redo <动作>`。

### 说明

- 撤销深度 60 条（跨页记录带 2–3 页快照，内存很小）。
- 仍保留 PencilKit 原生撤销作为兜底：切换文档后新建的 provider 不会继承上一本书的撤销历史（这是刻意的，避免跨书误撤销）。
