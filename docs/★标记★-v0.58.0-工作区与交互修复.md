## 行为与证据

- `diagnostics(1).log` 记录了双击选中 `Horizon`，但没有该次触点坐标；截图与用户说明表明预期为 `Edition`。日志未给出可归因的 PDF 打开错误。
- 【推断】旧选词路径混用了 `characterBounds(at:)` 的字形索引和 `selection(for:)` 的字符串 range，特定 PDF 的换行、文字运行序列可能不一致。本批统一为 range 几何，并在最终选区检查触点覆盖。新增每次双击的页码、视图坐标、页坐标与缩放诊断。
- PDF 导入原实现先移动 PDFKit 正在引用的临时文件，再访问页数与文字；本批提前读取元数据，拒绝零页文档。规范化生成串行化并使用唯一临时文件名，避免并发争用；打开失败自动尝试原文件和 64MiB 以下的数据读取，仍失败显示重试入口。重新导入同 SHA 文档可补回缺失本地文件并保留原记录。
- 激光笔不再每次落笔清空。尚未完全淡出的多笔统一恢复不透明，抬笔后统一从头淡出（0.65 秒）。完全到期后新笔不会复活旧笔；新一笔以独立子路径开始，不连线。
- 书架改为工作区：新建文件夹、改名、选择 12 种内置图标；全部/未归档/文件夹筛选；文档长按“移动到”；当前文件夹内导入自动归档；删除文件夹保留 PDF、进度、批注与生词。当前为单层文件夹，图标为 SF Symbols。
