# v0.47.0 — 自研墨迹引擎修复:方块 / 漂移 / 写完消失

> build 88 · `com.lei11118.pdfvocab` · 未签名 IPA(自签侧载)

这一版把 `diagnostics(7).log` 里的四个症状逐条修掉了,全部是**机制级**修复,不是调参。

## 1. 笔迹由小方块组成

**根因**:`InkMetalCanvasView` 的关节补丁是**轴对齐方块** —— 每个采样点补一个 2w×2w 的正方形,
折角处直接露出方块角。MSL 里字段名还写成 `float half`,`half` 是 Metal 保留类型名,
着色器编译失败 → 整条管线为 nil → 一个字都不画(0.46.1 已改名为 `hw`)。

**现在**:段用四边形 + **圆盘关节**(只在转角 > 20° 的点与两端生成,圆头、圆关节),
片元用 `fwidth` 做抗锯齿。没有方块,也没有折角缺口。

## 2. 一笔写下去变成几百笔

**根因**:`touchesMoved` 里把预测点写回了 `liveStroke`(`liveStroke = preview`),
而 `appendPoint` 遇到页外点会 `commitLiveRun()` 提交并把 `liveStroke` 置 nil —
紧接着预测点那段把它**复活**,于是每个移动事件都重新提交一次越来越长的同一笔。
日志证据:`metal ink: saved page 0 strokes=5 … 282`(2.8 秒内约 100 次/秒)。

**现在**:预测点只进渲染预览,绝不写回正在写的笔;提交只在**抬笔**和**落在页外**时发生。
旧数据里 0.46.x 写进去的重复副本会在加载时自动清理(`metal ink: cleaned page N a->b`)。

## 3. 笔迹没有固定在 PDF 上、不随页面滑动、写完消失

**根因**:
- `MetalInkHost` 对滚动**没有任何观察者** —— 页矩形只在 `refresh()` 时重算,
  屏幕上的墨钉在视图坐标里,等翻页才整块跳到新位置;
- `commit` 落库后没有重新映射,刚写的墨要等下一次滚动才出现。

**现在**:KVO 观察内部 `UIScrollView` 的 `contentOffset` / `zoomScale` / `contentSize`,
每次变化重算可见页矩形并把「页面坐标」墨迹重映射到视图坐标(墨永远贴着纸);
提交后立刻重映射,抬笔即见。

## 4. 墨迹跑到页面外

**现在**:两道硬边界 ——
1. 采样点落到所有页矩形之外就结束当前段,页外点不参与落库;
2. 落库前按页矩形把一笔切成若干段(页外段丢弃),渲染时再把页矩形传进**片元着色器**
   `discard`,连半个笔宽都出不去。

## 5. 顺带修好的

- **手指可以滚动了**:命中判定只接 Pencil,手指返回 `nil` 交给 PDFView(0.46 是无条件接管,
  所以单指滑不动);
- **撤销/重做**:自研引擎有自己的撤销栈(一笔一步,跨页一笔整体回退),不再出现
  `pencil: undo ignored (no canvas)`;
- **调色盘与笔宽生效**:`applyToolSession` 把 `PKInkingTool` 的颜色/宽度同步给自研引擎;
- **单引擎**:自研引擎生效时摘掉旧 PencilKit 逐页叠层,不再两套引擎同时落库;
- **单宿主**:重进文档复用同一宿主,不会叠出第二块画布。

## 真机验收清单

1. 写一笔:笔迹**圆润连续**,没有方块、没有重影;
2. 写完后停手:墨**留在原处**,不消失;
3. 单指上下滑:**页面和墨一起动**,墨不飘;
4. 双指缩放:墨跟着纸缩放,边缘依然锐利(矢量);
5. 写满页边:墨**不出页面**(页外空白处绝不出现墨点);
6. 画到页底跨到下一页:抬笔后两半各自留在本页原位;
7. 两指轻点:撤销一笔(再三点重做)。

## 已知缺口(下一版)

- 橡皮 / 荧光笔 / 蜡笔 / 形状 / 激光笔仍是旧 PencilKit 路径的工具语义,自研引擎目前只吃钢笔;
- 直尺吸附尚未接到自研引擎;
- 生词本整页重构、OCR 精度档设置未动。
