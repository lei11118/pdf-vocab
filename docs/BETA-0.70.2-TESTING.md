# v0.70.2-beta 测试说明

版本：`0.70.2`（build `120`）
用途：内部测试版。CI 回归和 IPA 构建结果待本次提交完成后回填；真机检查仍需使用 iPad。

## 本次改动

- Reader hover：修正文本/OCR 悬浮高亮矩形与实际词条位置的对齐，避免指针不变时反复重建高亮；关闭 Pencil 悬浮预览时清除残留高亮。
- Reader safe area：PDF 画布和坐标覆盖层延伸到屏幕边缘，在顶部和底部系统安全区绘制系统材质；阅读边距和自动滚动使用系统调整后的滚动内边距。
- 整句翻译的离线准备入口：完整句子翻译窗口显示英语 → 简体中文的检查中、已安装、可下载、不支持或失败状态。只有用户点击“准备离线翻译”时才调用 `TranslationSession.prepareTranslation()`；之后重新查询系统状态，准备调用成功本身不会被当作“已安装”。支持重新检查、失败重试和取消。入口不显示在悬浮胶囊中。

## 语言包范围和限制

本次只增加旧整句翻译窗口中的语言可用性和手动准备入口，不等同于 G3 语境对齐翻译交付。语境分段、与局部上下文及词义的对齐、GRDB 持久化和完整的语言包引导流程仍未全部完成。没有添加模拟译文。

真实语言包准备/下载和安装状态需要在 iPad 上验证；模拟器状态不能代替真机系统语言包行为。系统返回 `supported` 表示可下载，不表示已经安装。需在真机上检查按钮触发、下载进度/取消、状态刷新，以及安装后断网翻译表现。
