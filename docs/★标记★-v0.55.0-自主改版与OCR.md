# ★标记★ v0.55.0 / 98

已由用户确认离线 iPad 英文 PDF 阅读、手写、生词和图谱定位，并授权自主改版。采用 impeccable 原生 iOS 指导；保留原视觉身份。PRODUCT.md / DESIGN.md 记录约束。

## 改动
- LibraryView.swift：主页重组为继续阅读、学习工具入口、书架；入口为实际可操作按钮。
- VocabListView.swift：增加持久化紧凑/卡片浏览密度，保留拖动、筛选与导出。
- DesignSystem.swift：主要界面字体改用系统文本样式支持 Dynamic Type。
- OCRService.swift：逐页判断文本层；四块重叠高分辨率 Vision 识别，每块最多 6M 像素，顺序执行；映射回原页坐标并按重叠去重、重建行序。
- ReaderView.swift / ReaderCoordinator.swift：取消整本扫描分类门禁，允许混合 PDF 的扫描页使用 OCR。
- OCRStore.swift：缓存版本 3，旧缓存重建。
- InteractionPolishTests.swift：增加覆盖、重叠、混合页判定及小字识别回归。

## 调研依据与复用
- https://developer.apple.com/videos/play/wwdc2019/234/ ：复用 Vision accurate 识别与词级框 API。
- https://tesseract-ocr.github.io/tessdoc/ImproveQuality.html ：分辨率、裁切留边和倾斜的影响；不把 Tesseract 建议直接当 Vision 提升数据。
- https://github.com/SwiftyTesseract/SwiftyTesseract ：MIT 封装，尚未引入。
- https://github.com/PaddlePaddle/PaddleOCR/blob/main/docs/version3.x/inference_deployment/cross_platform/ios_deployment.en.md ：现成 iOS 推理路线，尚未引入额外模型。
- https://github.com/WeTransferArchive/WeScan ：扫描采集组件，已有 PDF 的 OCR 不需要重复接入相机扫描。
社区案例只用于定位方向，代码依据官方接口与回归验证。没有下载用户 PDF 到外部 OCR 服务。
