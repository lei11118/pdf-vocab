## 根因与限制

- **已确认源码根因**：此前选区去重键仅含页码、字数和文字 hash，相同页的相同单词会直接提前返回，留下旧选区。
- **推断**：此前只允许字符框外 2pt，可能解释部分双击失效；字间隙回归可验证几何改善，但不能覆盖所有真机时序和 PDF 文本层异常。
- OCR 文本层本身错误、无文本层且尚未完成 OCR、极密文字或重叠框仍可能需要原 PDF 分析。单个截图无法证明所有 PDF 均正常。
- 此次不改变长按/双击/三击规则，保留激光笔隔离、选区小柄和手写缩放机制。
- UI 截图属于模拟器静态验证；键盘、安全区在不同分屏宽度、真实拖卡、连续双击与工具切换需 iPad 验收。
