# 跃文 v0.35.0(build 73)

四条要求,逐条落实。每条都先说"查到了什么",再说"怎么改的"。

## ① 尺子固定在屏幕中间,移动视角不动

**查证**:PencilKit 只暴露 `PKCanvasView.isRulerActive` 一个布尔值,**没有任何可以设置直尺位置的公开 API**(Apple 官方文档 + Stack Overflow 一致)。它自带的直尺活在画布坐标系里,会跟着页面一起滚——无论怎么改参数都做不到"屏幕固定"。

**改法**:自己画一把尺子(`InkRulerOverlay`),挂在 `PDFView` 上、视口坐标:
- 位置永远是**视口中线**,滚动、缩放、旋转都不动;
- 不参与触摸(`isUserInteractionEnabled = false`),不抢笔、不挡选词;
- 只在书写模式显示,退出书写自动收起;
- 关闭再打开就是一次"重置"——它本来就没有位置状态,永远回到中线;
- 吸附:贴着尺子画的那一笔,抬笔后把所有采样点的 y 压到尺子线上,画出来与尺子完全平行(容差 30 页面点);没贴尺子则走原来的直线吸附;
- PencilKit 自带直尺**永久关闭**,避免屏幕上一横一竖两把尺子。

## ② 缩放下限就是 100%

**查证**:上一版我把下限改成了 0.2(允许缩小),方向错了。你要的是**下限 100%,不允许更小**。

**改法**:`minScaleFactor` 三处全部钉成 `1.0`(创建、`updateUIView`、每次缩放时重新钉),并移除 50%/75% 两个低于 100% 的预设。PDFKit 会偷偷把下限恢复成它自己的默认值,所以缩放观察者里每次都重新钉一遍——这是上一版"改了没成功"的原因。

## ③ 一笔跨三页及以上,而且必须是一体的

**查证**:跨页是"按页边切分 + 把越界段搬给邻页",一次只搬一步;邻页若还越界,它自己的结算会被递归保护挡掉 → 长笔卡在中间页。

**改法**:
- 结算时记录"这次搬到了哪几页",收尾后**接着结算邻页**,一路传下去,直到某页装得下;
- 页面叠层翻出来时也结算一次(之前写进墨迹库的中间页会被补齐)。

**"一体"的三条保证**:
- 切分出来的各段**共享同一个 `creationDate`**,系统层面仍认作一笔;
- 撤销:搬页时把两页并进同一条撤销记录,一次撤销整笔消失;
- 橡皮(整笔模式):命中任意一段 → 按 `creationDate` 家族把**所有页**上的同源段一起删掉。

## ④ 工作方式

已记住:改前先读源码、列计划;发现问题直接改不追问;改完逐条列出;不猜,不确定就查(官方文档 / GitHub / Stack Overflow)。

## 安装与验收

`PdfVocab-unsigned.ipa`,AltStore / SideStore / Sideloadly 自签安装,Bundle ID 未变,覆盖安装不丢数据。

1. 开尺子:屏幕正中一条横线;**滚动页面、缩放**,线不动;关掉再开,仍在正中;
2. 贴着尺子画,出来的线应与尺子完全平行;
3. 捏合缩小:停在 100%,不能再小;
4. 一笔从第 2 页画到第 4 页:抬笔后三段各自落在对应页、首尾相接;撤销一次全消失;
5. 整笔橡皮点一下跨页那笔:三页上的墨一起消失。
