# 跃文 v0.37.0(build 75)

> 两条新要求:尺子做成原版那种「尺身」、胶囊词卡与其它窗口互斥。另外合并了上一版没发出去的跨页重影修复。

## ① 直尺:自绘,形状像原版

PencilKit 只公开 `isRulerActive`,**没有定位 API**(Apple 文档与社区一致),它自带的尺子活在画布坐标里会跟着页面滚 —— 做不到你要的"固定屏幕"。所以仍然是自绘,但外观按原版做:

- **半透明尺身**(22pt 高的圆角条)+ 短/中/长三档刻度(每 30pt 一格,长刻度带数字);
- 两端握把记号,一眼能认出是尺子;
- 位置永远是视口中线,滚动/缩放/旋转都不动;关闭再开启仍是中线;
- 不参与触摸(`isUserInteractionEnabled = false`),不抢笔、不挡选词;
- 贴着尺子画的那一笔,抬笔时把所有采样点压到尺子线上,出来的线与尺子完全平行。

## ② 胶囊词卡与其它窗口互斥

以前词卡和弹层可以同时存在:两窗叠在一起时,卡片被压住,**连拖都拖不出来**。

改法:
- 任何弹层打开(页码跳转 / 设置 / 生词本 / 目录 / 搜索 / 词频)先收起词卡;
- 进入书写模式时也收起词卡与弧形工具盘 —— 底下是工具条,压着同样拉不动。

## ③ 合并:跨页墨迹重影(上一版没发出去)

上一版 v0.36.0 的修复这次一起进包:

- 位移改用**两页真实页矩形对齐**(实测 page 0 画布高 6070、其余 6069,按"一页高"会偏出 1pt,导致两页来回弹);
- 越界容差 0.5 → 1.5 画布点;
- `handoffHistory` 防弹回(1 秒内反向搬回 → 保留页内段、丢弃越界段);
- 搬页前按 `creationDate` + 位置去重;**页面加载时自动清掉已经画坏的重复段**(日志 `page N dedupe 49 -> 12 strokes`)。

## 安装与验收

`PdfVocab-unsigned.ipa`,AltStore / SideStore / Sideloadly 自签安装,Bundle ID 未变,覆盖安装不丢数据。

1. 开尺子:屏幕正中一条半透明尺子(带刻度与数字);滚动、缩放都不动;关掉再开仍在正中;
2. 贴着尺子画,线与尺子平行;
3. 点词弹出卡片后,再点开"目录/搜索/设置"任意一个:卡片应先收起,不会叠加;
4. 从选词切到书写模式:卡片与弧形工具盘都应收起;
5. 黑笔由下往上滑跨页缝:不再出现重影与错位碎片。
