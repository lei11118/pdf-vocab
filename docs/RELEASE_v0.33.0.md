## 修的两个问题

### ① 横向排布下,跨页搬到了错误的页

日志开头 `display: layout=horizontal` —— 你这本是在**横向连续**(左右翻页)下读的。

而 v0.32.0 的跨页只按**上下方向**切:凡是越过页面底部的笔迹,都当作"要流到第 N+1 页",平移一个页高交给下一页。横向排布时"下一页"在**右边**,于是:
- 笔迹/图形被搬去了右边那一页的顶部;
- 搬过去之后又超出那一页的画布范围 → `stroke hit canvas edge (bleed exhausted)`,被裁掉。

这就是你看到的"图形跑到隔壁页 / 图形被切"。

**改法**:跨页方向跟着排布走。
- 纵向连续 → 只处理**上下**越界,位移 = 一页高;
- 横向连续 → 只处理**左右**越界,位移 = 一页宽;
- 另一个方向没有邻页,不做任何搬移(以前会乱搬)。
- 切换排布时(`setLayoutMode`)同步更新方向,翻页方向变了跨页方向立刻跟着变。

### ② 湿墨预览会永久残留("幽灵墨迹")

日志里只有 `wet begin epoch=2` / `epoch=3`,**一条 `wet end` 都没有** —— 观察笔迹结束的手势识别器没有稳定收到结束回调。结果:那一层"页外墨迹实时预览"永远不会被撤掉,屏幕上会留一段不属于任何笔迹的墨,看起来就像图形画歪了、页边多了一条。

**改法**:
- 画布内容一旦落定(干墨接手)就无条件撤掉预览,不再因为"这一笔还没结束"而卡住;
- 采样间隔超过 1 秒没有新点,就当作新一笔开始,自动换新(兜住结束回调丢失)。

## 验收

1. 横向连续下,从左页右边缘写到右页:抬笔后墨迹应出现在**右边那一页的左边缘**,连续不错位;
