# v0.63 阅读器交互与端侧全文翻译

## 操作

- 知识图谱：拖动节点标题移动，四角缩放；选择/移动模式可拖动整个节点。拖拽即时跟随，不做滞后插值；适应画面使用平滑动画。固定全局坐标、手势初始矩形、临时画面状态及松手提交，取消手势亦会收尾。
- 弧形工具盘：初始圆弧 108°；弦方向相对屏幕水平线向左倾 53°，左手模式镜像。工具在圆周两端继续展开，不再预先绘制淡化工具。超出一组圆弧容量可用上一组/下一组切换。
- 捏压按下时开关，PDF 与覆盖层共用去重器；工具盘不再禁用承载 Pencil interaction 的 PDFView。已翻译悬停词仍可优先朗读。
- 工具盘“自定义工具”：编辑基础工具、颜色、宽度等并以名称保存独立预设；可删除、排序及隐藏/恢复基础工具。
- 阅读器自有的设置、目录、搜索、生词本、页码、缩略图、图谱、全文校对、句子翻译、清空手写确认等使用可移动、可缩放、可折叠胶囊窗。系统文件选择、分享、语言包下载授权仍使用系统界面。
- 单词卡和悬浮释义不再截为首行/八行，保留各已启用词典的完整释义与英英定义，小窗中滚动阅读。悬浮位置以文字框顶部为锚点，向上展开；屏幕上方空间过小时不遮盖原词。

## 全文翻译与校对

按用户选择采用 Apple Translation 端侧引擎，不配置网络模型，不上传文档到自建服务。系统语言包需由系统下载/授权；全文翻译 API 需要 iPadOS 18+，旧系统保留阅读和词典能力并提示版本限制。

文档打开后先完成原有逐页 OCR（有文字层不重复 OCR），从原 PDF 文字/OCR 缓存按句解析，批量进行英→简体中文翻译。每批持久化后更新进度，可暂停/继续/重试，重新打开按句 ID 续译。主数据库中的 `document_translation` 表随原数据库备份。

每条记录保存文档归属、页码、句子原文及 UTF-16 范围；源词与译文跨度关联按具体出现位置保存，重复词不共享校对。自动链接使用本地词典候选与实际句译匹配，不把位置比例或任意邻词当成对齐；未匹配词明确标待校对。自动链接仍可能选错义项，不是人工确认，不宣称全词覆盖或达到神经对齐模型准确率。

全文校对窗按页显示所有句子。可修改句译；点击源词可保存该处语境释义，若释义出现在句译中也保存目标范围。人工校对结果由数据库写入保护，不被后台续译覆盖。页面悬浮词卡与弹窗显示“校对”区，再保留各词典来源完整释义；整句弹窗优先复用对应已校对句译。

## 开源调研

- awesome-align：多语言 BERT 对齐，BSD-3-Clause，Python/PyTorch 流程；https://github.com/neulab/awesome-align
- SimAlign：预训练嵌入的词语对齐，MIT，Python/Transformers/Torch；https://github.com/cisnlp/simalign
- 两者已有可用开源对齐思路，但没有直接复制嵌入本 App；按用户选择，不增加大型 Python/模型运行时，自研 Swift 端的保守词语链接与人工校对层。
- Apple Translation / 批量翻译官方文档：https://developer.apple.com/documentation/translation/ ，https://developer.apple.com/documentation/translation/translationsession/translate(batch:)

## 验证边界

CI 覆盖原有选词、链接、OCR、墨迹等回归，并新增 UTF-16/重复词语境链接、无匹配不得伪造、人工校对缓存防覆盖、释义完整性、捏压去重、窄屏极坐标命中及新窗口截图。

模拟器不能完成 Apple 离线语言模型的真实翻译质量验收，也不能替代真实 Pencil Pro 的捏压/悬停/手掌仲裁、120Hz 跟手性或 873 页整本的耗时/耗电验收。自动词语链接不是语义神经对齐模型，低覆盖或歧义仍需人工校对。
