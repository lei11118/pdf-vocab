- `Sources/Reader/Ink/InkMetalCanvasView.swift`：移除只有转角超过 20 度才补关节的条件；任意弯曲关节补外侧圆弧楔形，避免密集窄裂缝；使用按像素误差计算的圆弧细分，保留每笔最大覆盖混合，避免荧光笔关节反复加深。仅补缺口圆弧，控制顶点和显存开销。
