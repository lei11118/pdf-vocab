## 跃文 v0.26.0（build 65）

未签名 IPA，用 AltStore / SideStore / Sideloadly 自签安装；重签不丢数据。

### 1. 所有页合并成一张长纸

以前虽然页与页之间没有间距（`pageBreakMargins = .zero`），但 PDFKit 仍在每页之间画**页影**和**分隔线**，看起来还是"一页一张纸"，跨页书写时笔迹在页缝处断开。

- 关掉页影（`pageShadowsEnabled = false`）与页间分隔线（`displaysPageBreaks = false`）；
- 切换「纵向 / 横向 / 双页」排布后**重新钉住**这三项（PDFKit 换 `displayMode` 时会把它们恢复默认，这是以前换个排布页影又回来的原因）；
- 手写叠层改成不裁剪页外内容（`clipsToBounds = false`），书写跨过页缝时笔迹**连续可见地**越过边界，不再"写到页边消失、抬笔才跳到下一页"。命中判定仍按本页范围，不会抢走邻页的触摸。

### 2. 每支笔都有自己的状态，并按书记住

以前墨色与笔宽是**全局一份**：用荧光笔调到最粗，切回钢笔，钢笔也变成 24pt；铅笔的粗细被钢笔的档位带走。

- 新增 `PencilToolPrefs`：钢笔 / 铅笔 / 书法 / 荧光笔 / 蜡笔 / 橡皮各自保存 **墨色、自定义色、笔宽、笔锋角度、稳定化、橡皮模式与大小**；
- 切到哪支笔就装回哪支笔自己的值，互不污染；
- 状态表以 JSON **全局 + 按书双写**（`pencil.state.global` / `pencil.state.<sha>`），进入文档时整份装回；老的逐键记录会自动升级，不用手动重设；
- 只有你**显式开关/选值**时才写入状态，进文档、退出、切页都不会改动它。

### 真机验收要点

1. 上下滚动过页缝：应当看不到页影、分隔线、白边；在页缝正中画一笔横线，笔迹连续。
2. 钢笔调细 → 切荧光笔调到最粗 → 切回钢笔（仍细）→ 再切荧光笔（仍最粗）→ 书法笔调笔锋 90° → 回文档库 → 重进同一本书：四支笔各自保持。诊断日志关键字 `doc state loaded tools=`。

### 已知上限（未在本版处理）
