# 跃文 v0.31.0(build 67)

> 这是一次**回归修复版**:撤掉把工具改坏的三版手写重构,回到你上次能正常写字的实现,再补上三条修复。

## 你报的三个问题的处理

### ① 所有工具异常,除橡皮/尺子外都只有黑笔效果

**根因**:v0.28.0 起,工具应用被改成"延迟到下一个 runloop 再套用",并且在**排队之前**就记下了"已套用签名"。当那一刻绘制层(provider)还没建好,任务直接 return,而签名已经是新的 —— 之后再没有任何人重套一次。结果每块画布永远停在 `PKCanvasView` 初始化时的保底黑笔:`PKInkingTool(.pen, .black, 2.5)`。橡皮和直尺之所以正常,是因为它们走的是同步的 `setEraserMode` / `setRulerActive`。

**修法**:
- `v0.28.0 / v0.29.0 / v0.30.0` 三版整体 `git revert`,手写栈回到 v0.27.0;
- 工具套用**改回同步**;provider 未就绪时**不记签名**(等下一次调用);
- 画布每次进入书写都向 provider 再取一次当前笔具 —— 创建、复用、层级重建漏套的情况都被兜住。

### ② 直尺出现多个,应只在屏幕中间一个

**根因**:PencilKit 的直尺是**每块 `PKCanvasView` 各带一把**。以前对所有页画布都设了 `isRulerActive = true`,同时可见的几页就各画一把。

**修法**:直尺只挂在**视口中心那一页**的画布上;滚动、缩放、旋转时用 `refreshRulerFocus()` 把它挪到新的焦点页。屏幕上永远只有一把。

### ③ 从第 2 页向上写、接第 1 页仍被截断

**根因**:向上搬运的位移要按**上一页的页高**算。上一页的叠层常常还没创建(PDFKit 只为可见页建叠层),老代码这时退化成"当前页页高" —— 遇到封面、插页等尺寸不同的页就会错位;搬运失败时源笔迹又不会被裁剪,留在出血区里正好被上一页的页视图盖住,看起来就是"截断"。

**修法**:拿不到叠层尺寸时,改用**文档里的页面尺寸**;两页仍共享同一个边界插值点,页缝两侧是同一笔。

## 为什么整版回退,而不是继续修

v0.28–v0.30 那三版是"工具状态单一真相源 → 四边贯通 → 跨页只渲染不搬迁"的连续重构,彼此咬合:回退其中一版编译不过,单独打补丁又会把跨页行为带回不确定状态。它们引入的收益(状态集中、湿墨/干墨层)在真机上被三个硬事实否定:

1. 工具套用一旦变成异步,就存在"签名已记、provider 未就绪"的死窗口;
2. 每块画布自带一把直尺,不能对所有页开;
3. 跨页墨迹只能靠**抬笔切分搬页**,在 PDFView 上加"镜像画布"会被 PDFKit 翻页重建的页视图压到下层,页缝处正好被裁成截断。

这三条已写进 `docs/HANDOFF.md` 的「v0.31.0 回退说明」,后续不要重走。

## 保留下来的能力(与 v0.27.0 一致)

Notability 式工具状态机、钢笔/铅笔/书法/荧光笔/蜡笔/套索、自研橡皮(五档 + 局部/整笔)、**统一撤销组**(跨页一笔只回退一次)、跨页书写(上下)、直线吸附、形状工具(直线/矩形/椭圆/箭头)、激光笔、4000% 缩放、页面缩略图、每书工具记忆、工具条自由拖动。

## 本次要重点确认的三件事

1. 切换到钢笔/铅笔/荧光笔/蜡笔/套索后,**墨色与笔宽是否真的跟着变**(不再一律黑笔);
2. 打开直尺后,屏幕上是否**只有中间一把**;滚动到下一页,尺子是否跟过去;
3. 在第 2 页顶部往上写、越到第 1 页,页缝处是否**连续不断**。
